# Disease Prediction System — Educational Demo

**Tech:** Pandas, scikit-learn Random Forest, Streamlit.

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

This demonstrates a classification workflow only. Its tiny synthetic dataset is **not medical evidence**; the app must not be used for diagnosis or treatment decisions. Replace it only with appropriately governed, clinically validated data and expert oversight for any serious research.
